# ChatGPTMND

The pigeon has administrator privileges. A static, YTMND-inspired meme with an original image, looping music, and animated text.

Open `index.html` in a browser, then choose **LET HIM COOK** to start. Use the playback, sound, volume, and motion controls below the meme. Space toggles playback; M toggles sound when a control is not focused.

No build or installation is needed. Keep `pigeon.png` and `loop.wav` beside `index.html` when opening the page locally.

For GitHub Pages, publish the `main` branch from `/ (root)` in the repository's **Settings → Pages**. The public site is https://hawby.github.io/ChatGPTMND/.
